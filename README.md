# StyleKart — React E-Commerce Frontend

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Features
- Responsive home, shop, product details, cart, wishlist, login/register demo, checkout demo, about, contact and 404 pages.
- Search, category filters, max-price filter, sorting, product quick-add.
- Cart and wishlist persist in browser localStorage.
- Demo checkout clears the cart and displays a confirmation screen.
- Responsive custom CSS, Bootstrap, React Router and React Icons.

## Important
This is a frontend learning project. Product prices, ratings, policies and images are sample/demo content. Login/register is not real authentication. Checkout does not take payments or place real orders. Do not use real customer passwords or payment details.

## Images
Product photography loads from Unsplash over the internet. A network connection is needed for those images.
